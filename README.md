# Algoritmos-II-Consulta
### Objetivo
Repositorio destinado para guiar a los estudiantes que cursan la materia de Algoritmos y Estructura de Datos II.
### Temas abordados:
- Listas enlazadas (Lenguaje: C)
- Pilas (Lenguaje: C)
- Colas (Lenguaje: C)
- Pruebas de escritorio
- Árbol binario
- Árbol 2-3
- Árbol b+
- Hashing
- Grafos

> Este repositorio está pensado como material complementario a las clases y recursos oficiales de la cátedra
